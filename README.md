Aurora is an online-based compiler that allows logged-in and anonymous users to use the compiler. The compiler has a challenges
page and community pages. The challenges page is basically a section where you can view activities and attempt them for personal
knowledge gain. The community pages is a section where you can discuss with other users about coding and software development.
The compiler's anonymous users can make use of three languages (Bash, JavaScript, and C#) in the compiler and can 
read through the challenges and community pages. The contributions and use of the full languages suite are only available to logged-in users. 
The profile will track how many challenges are completed, the date the profile was created, and the different languages 
they use.
